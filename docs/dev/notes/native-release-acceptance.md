This is the finishing checklist for the agreed Windows native OBJ/SOP milestone.
An implemented feature with a scoped test is not automatically certified for all
production assets. Solaris expansion, baking, deep output, arbitrary LPEs, OSL
and other platforms remain outside this milestone.

1. Close the remaining documented feature contexts: genuinely varying per-key shader
   assignments and stylesheet subjects, broader dynamic resource contexts, remaining
   geometry/volume adapters and animated projection optics. Shutter-sampled uniform
   instance fields and native whole-ramp/curve overrides are implemented and scoped-tested.
   Uniform whole-curve source-key bindings, bounded numeric/channel override expressions
   and continuous shutter-sampled depth of field are implemented; their current
   contracts and verification boundary are in [binding, expression and optics coverage](native-binding-expression-optics.md).
   Every addition keeps the local diagnostic and repair policy. Existing valid
   components must continue rendering when another source is unsupported.
   Camera-coordinate invalidation and local scene-query true-displacement
   recovery are implemented and scoped-tested. The latter omits unavailable
   effects while retaining valid surface and independent height.
2. Complete the remaining measured mixed-capture/family/lighting bottlenecks. Compare
   retained and forced-work controls with identical inputs; retain exact output,
   source identity, motion and ownership. Verified homogeneous named-array
   retention is implemented. Avoid adding artist execution modes.
3. Run the combined correctness matrix on CPU, each individual OptiX GPU and
   mixed devices, including final output, both viewers, live break/repair,
   cancellation, saved-scene replacement and strict internal failures.
4. Certify latency, memory and presentation: warm one-million-triangle 960x540
   fixture; camera p95 at most 150 ms and transform/material p95 below 500 ms;
   no camera-only geometry conversion/upload; separate cooking and total
   latency; heavy pending geometry, 1k/10k/100k instances, 1080p/4K, monitor
   changes and prolonged ownership/process/device memory observations.
   Physical viewport input remains a separate check from programmatic edits.
5. Certify the relocatable package, explicit installation/rollback, matching SDK
   dependency providers, pinned license notices, reproducible final hashes and
   clean-machine startup. Basic internal package and isolated installation/
   recovery operations, matching SDK OIDN providers and deterministic internal
   reproduction are implemented and scoped-tested. Finish the artist-facing UI review
   against the agreed controls.

Local edition checks used Houdini Indie 22.0.466. A Core or FX compatibility
claim requires evidence from that commercial edition on the exact package.
Verify definition loading and license category, create Cycles Light and Blender
File nodes, and save and reopen a scratch `.hip` under the commercial checkout.

The coordinator batches independent changes into one immutable runtime, then
runs selected regression cases serially. All source writers stop before native
builds and tests. `scripts/verify-native-release.ps1 -Cases <file> -Name <name>`
accepts an explicit JSON array of test/device/report selections. It archives
each terminal test and its exact source set before proceeding, including failed
runs. Its result describes only those selections, not this entire checklist.

`tests/houdini_release_response_gui_smoke.py` measures the defined warm fixture
through the Cycles canvas paint callback, with one native viewport and one
viewer. It records 30 observations per edit class by default, a nearest-rank
p95, source cooking/extraction counters, unchanged geometry conversions, buffer
requests, worker identity and host memory observations. Low-resolution fresh
previews may count; retained old pixels may not. A correctness pass and the
prospective latency budgets are separate report fields. This check does not
certify physical input, compositor presentation or a memory plateau.

The earlier protocol-48 combined runtime passes 40 selected source-archived native runs,
including five final relocated-package checks. Its warm fixture meets the
prospective response budgets on both individual GPUs. This closes those scoped
checks without certifying physical burst input, sustained physical memory,
arbitrary production assets or a clean-machine public release.
