# Records of past work

Each document here records one measurement, review or change at the time it was made: what was tried, the numbers
that were measured and what was decided then. They are kept because decisions and patch records cite them. They are
not maintained: names, counts and paths in them describe the project as it was on the date given, and later work may
have changed or replaced what they describe. For how things work now, start with the
[developer guide](../dev/README.md).
