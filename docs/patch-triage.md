# Renderer patch triage

Source-derived local triage of all locked patches. Upstreamable means a candidate requiring extraction/review/evidence, not upstream acceptance or an executed regression. Fork-permanent means maintained until an explicit renderer API/design replaces it. Nothing was transmitted externally.

Every row is bound to its exact patch SHA-256 in [triage.json](../patches/triage.json). The [patch inventory](../patches/inventory.json) records touched files, overlap predecessors and related fixture contracts. The local fork contains all 116 listed commits.

upstreamable: **80**, fork-permanent: **26**, integration-only: **10**.

**Upstreamable** identifies a generic correction or optimization to extract and review. **Fork-permanent** means a maintained feature/API until an agreed replacement exists; it is not a claim that upstream will never want it. **Integration-only** contains host build/provider/owned-data/policy seams. All dispositions require the inventory retirement gate before removal: upstream equivalent, independent successor replay, affected backend checks and feature-off controls.

Local proposal drafts: [light-tree cache and reuse](dev/upstream-light-tree-proposal.md), [nested medium transport](dev/upstream-nested-medium-proposal.md), [small correctness fixes](dev/upstream-correctness-proposals.md). These are source-backed review packets with explicit evidence gaps, not submissions or upstream approvals. No external service was contacted or message transmitted.

Validate with `python scripts/patch-triage.py --check`; regenerate this table with `--write`.

The policy column implements [ADR 0005](decisions/0005-cycles-fork-policy.md). Features reference its whitelist and fixes reference the upstream queue. Measurements, retirements and historical exceptions apply only to the recorded bytes. Runtime glue outside build files requires an explicit hash-bound review. Kernel changes cannot enter as glue. The eight approved session/output patches under src/integrator/ have a separate hash-bound scope.

Patch IDs remain stable when earlier patches retire; gaps are intentional. The nine approved features, including interactive light-tree updates, remain in production.

The integration archive preserves the complete adapter, original lock and patch bytes; the engine archive preserves the matching fork. The branch and commits refer to private archives and are absent from public clones. The pair can return only together under one kernel mechanism, ADR and kernel-surface budget.
