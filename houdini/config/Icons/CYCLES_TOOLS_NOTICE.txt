The Windows installer icon (../branding/installer.ico) is rendered from
cycles_render_rop.svg. The raster conversion uses a transparent 256-pixel
square and saves seven icon sizes. The derived installer icon is also under
GPL-2.0-or-later.

To regenerate it from the public source, run this from the project folder
with PyMuPDF 2.1 (which uses MuPDF 1.28.6) and Pillow 12.3.0:

    python scripts/export-branding.py --icon-only --output _work/branding

The icon recipe uses only cycles_render_rop.svg. On Windows it reproduces the
RGBA pixels at all seven sizes. The encoded ICO bytes can differ. The wordmark
source artwork is used by the separate full branding export.

Note A: these two drawings were made for this project in 2026 and are
released under CC0 1.0 (see cycles_viewer/LICENSE for the text), to the
extent that any rights in them exist.

The project logo (../branding/cycles-houdini-logo.svg and .png) is an
original drawing made for this project, 2026, released under CC0 1.0 by the
project's author on 21 November 2026. The
installer's welcome and header images (../branding/installer-welcome.png,
installer-header.png) are generated from that logo by
scripts/export-branding.py and are covered by the same release. CC0 concerns
copyright only.

How the origins were found: every icon was rendered and compared shape by
shape with the 799 icons of Blender v5.3.0 release/datafiles/icons_svg; the
named Blender icons match at 95-100% overlap.

About CC BY-SA 4.0: in February 2019 the designer of Blender's 2.80 icon
sheet wrote on Blender's developer forum that his icon sheet was available
under CC BY-SA 4.0. That statement covers his sheet as it was then; it has not
been checked icon by icon against these files, so this notice relies on the
GPL, under which Blender itself distributes them.
